# 🧠 Smart Cart - Decision Engine

> **Not a price comparator. A decision engine.**
> **Last Updated**: 2026-06-25

---

## 🎯 WHAT THIS PROJECT ACTUALLY IS

### The Core Philosophy

**People don't want prices. People want decisions.**

- Amazon gives prices.
- Blinkit gives prices.
- Instamart gives prices.

**We give answers.**

When a user asks "I need oats", we don't show 50 options.
We figure out:
- Which oats? (Rolled? Instant? Steel cut?)
- What's their preference? (Organic? Brand? Budget?)
- What do they buy every month?
- Where's the best deal RIGHT NOW?
- And we say: "Buy this."

### What We're Building

**A personal shopping decision engine that:**
1. Understands what the user actually means
2. Reasons across multiple platforms
3. Recommends the best purchasing decision
4. Explains WHY with confidence

---

## 🧭 THE NORTH STAR

### Every feature must answer one question:

> **"Does this make the engine better at understanding the user and making trustworthy decisions?"**

If yes → Build it
If no → Don't

### What We Optimize For (In Order)

1. **Confidence** - User trusts the recommendation
2. **Understanding** - Engine knows what user really wants
3. **Context** - Considers history, preferences, timing
4. **Clarity** - Explains WHY in simple terms
5. **Price** - Yes, but it's only ONE signal
